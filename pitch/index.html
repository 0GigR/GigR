03 / The On-Chain Escrow (Anchor)

// gigr_escrow: Secure payment rails pub fn init_escrow(ctx: Context<InitEscrow>, job_id: u64, amount: u64) -> Result<()> { let escrow = &mut ctx.accounts.escrow; escrow.client = ctx.accounts.client.key(); escrow.provider = ctx.accounts.provider.key(); escrow.job_id = job_id; escrow.amount = amount; escrow.bump = ctx.bumps.escrow; // CPI: Transfer USDC from client to vault ATA let cpi_ctx = CpiContext::new( ctx.accounts.token_program.to_account_info(), Transfer { from: ctx.accounts.client_ata.to_account_info(), to: ctx.accounts.vault_ata.to_account_info(), authority: ctx.accounts.client.to_account_info(), } ); token::transfer(cpi_ctx, amount)?; Ok(()) }

Escrow Program Integrity

  • Safe PDA Derivation: Seeds match [b"escrow", client_pubkey, job_id_bytes]. Escrow address is deterministic and cryptographically unique.
  • Platform Rent Funding: The system/escrow PDA rent is paid by the platform key, enabling gasless/rent-free user onboardings.
  • Automatic Rent Recovery: On release or cancel, the vault ATA and PDA are closed, refunding the lamport rent back to the platform wallet.

04 / The Invisible Web3 Layer

Custodial Creation

On standard Google login, Gigr automatically creates a custodial Solana keypair. The keys are encrypted via AES-128 and managed safely behind API credentials.

Gasless Signatures

Platform acts as the transaction fee-payer for every interaction. Users sign operations implicitly through API endpoints without using Phantom or Metamask.

Naira / USDC Ramp

USDC values are dynamically shown to the local user in Nigerian Naira (₦). A direct fiat on-ramp will execute cash-to-token trades seamlessly in production.
