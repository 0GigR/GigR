03 / The On-Chain Escrow (Anchor)

pub fn init_escrow(ctx: Context<InitEscrow>, job_id: u64, amount: u64) -> Result<()> { let escrow = &mut ctx.accounts.escrow; escrow.client = ctx.accounts.client.key(); escrow.provider = ctx.accounts.provider.key(); escrow.job_id = job_id; escrow.amount = amount; escrow.bump = ctx.bumps.escrow; // CPI: Transfer USDC to vault ATA let cpi_ctx = CpiContext::new( ctx.accounts.token_program.to_account_info(), Transfer { from: ctx.accounts.client_ata.to_account_info(), to: ctx.accounts.vault_ata.to_account_info(), authority: ctx.accounts.client.to_account_info(), } ); token::transfer(cpi_ctx, amount)?; Ok(()) }
  • Safe PDA Derivation: Seeds match [b"escrow", client_pubkey, job_id_bytes]. Escrow address is cryptographically locked to the specific transaction.
  • Platform Rent Funding: Escrow space rent is funded by the platform fee payer, keeping users free from wallet fees during initialization.
  • Automatic Rent Recovery: Escrow is automatically closed on completion/cancellation, returning lamport rent back to the platform.
